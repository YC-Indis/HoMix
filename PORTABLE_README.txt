HoMix 0.20.5 Windows x64 团队版

1. 请先完整解压整个 HoMix 文件夹，不要直接在压缩包内运行，然后双击 HoMix.exe。
2. 程序启动后会直接打开 HoMix 桌面窗口；重复双击会唤醒现有窗口，不会重复启动后台。
3. 关闭主窗口会同步结束 Node、FFmpeg 和文件选择等后台进程，不会影响下次启动。
4. 请保留整个 HoMix 文件夹，不要只复制单独的 EXE。
5. 目标电脑需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime；多数系统已自带，若启动时提示缺失，请安装或修复 WebView2 Runtime。

本发行包已包含独立的 FFmpeg 8.1.2 Essentials，位于 tools 文件夹，并附带
LICENSE 与 README.txt。运行时优先使用该版本，不依赖 ECutPro 或系统 FFmpeg。

0.20.5 更新桌面工作台界面、三阶段工作流与本地项目入口，并修复空项目状态下的界面初始化问题。

GLM API Key 可在“AI 设置”中填写，并使用 Windows 当前账户的 DPAPI 加密保存，不会明文写入项目文件。

0.6.0 改用单实例 WebView2 原生窗口，支持从 Windows 资源管理器直接拖入视频，并取消慢速 PowerShell 文件选择器。FFmpeg 使用较低优先级并分组生成缩略图，减少系统卡顿。每个非末段结尾默认提前 1 帧，该帧直接丢弃，不补入下一段。
0.7.0 修复 175% 等高缩放下主窗口和文件选择器模糊；缩略图提升为 720px。顶部常驻本地项目入口。脚本匹配只使用已完成视觉理解的镜头，锁定片头/片尾位置、原片正序并跨历史方案去重。导出前检查源视频损坏帧，阻止马赛克输出。
0.8.0 增加项目安全删除；修复小窗口纵向滚动。HoMix 可自动启动 Ollama、识别视觉模型并从设置页安装 qwen3-vl:4b。切分改为原始帧 PTS 半开区间，不再人为提前或丢弃尾帧。视觉标签综合镜头开头/中间/结尾三帧，并把连续性标签用于项目与星标素材库混剪。
0.9.0 产品主流程调整为 B-roll 精细切片与钩子换画面。默认保留闪切并识别黑场边界；镜头支持逐帧修正入点/出点。钩子工作台可保留整条原音频、替换后段画面，并逐段选择直切、黑场或交叉溶解。
0.10.0 主流程收拢为三步：空镜素材拆分、钩子与音乐提取、钩子与空镜组合。钩子分析会生成独立音乐文件；确认结束帧并锁定模板后，才能进入组合时间线。
0.11.0 空镜默认改用连贯拆分，保留相似转场与连续动作。钩子支持批量导入和视觉/叙事逻辑判断，高置信度自动确认。组合阶段取消人工筛选数量限制，直接从全部空镜按音乐剩余时长自动铺满并支持批量导出。
0.12.0 三个阶段改为同一主界面的同级页面。空镜和钩子可首次一起导入并行处理；钩子批量识别采用置信度分流并取消确认阶段的画面预编码。自动组合默认硬切，时间线显示缩略图、来源和时间码，支持单段检查及整条低清预览。
0.14.3 预览改为同项目单任务：切换钩子或步骤会立即取消上一条 FFmpeg 任务并停止所有播放器。修复通信中断显示 JSON 错误，并将不足 0.35 秒的尾部需求合并到上一镜头，避免超短片段无可解码帧。
0.15.0 自动识别空镜横竖屏：竖屏直接使用，横屏在竖版成片中生成三层堆叠画面；自动铺满优先保持同布局连续。步骤一加入框选批量星标入库，步骤三改为左侧监看、右侧纵向逐条队列，并将新建项目、打开项目、抽屉、素材库、设置与文件选择等界面切换统一纳入停播规则。
0.15.1 修复 720×1280 正式导出时三宫格单层高度被计算为奇数、导致 YUV420 编码器无法配置画面的错误。三宫格改为偶数高度单次缩放后复制三层，降低滤镜开销并统一预览与正式导出的行为。
0.16.0 素材、钩子和音乐改为独立可选，支持纯混剪跳过步骤二、仅钩子直接导出。第三步增加人工选片、替换、增删、调序、片段时长、音乐选择与入点控制；确认成片后跨任务锁定已用片段。钩子可进入星标库，星标内容改为仅手动加入项目。EXE 使用 WebView2 桌面窗口，原生选择文件，并在窗口关闭时结束完整后台进程树。
0.16.1 启动阶段不再检测或启动 Ollama，也不再提前解密 GLM Key；进入 AI 设置或实际执行视觉分析时才按需检测。WebView2 初始化失败会自动等待并重试，关闭后立即重开更加稳定，启动时不显示终端窗口。修复步骤一“下一步：确认钩子”因过期界面元素导致点击无响应的问题。
0.16.2 禁止桌面工作台缓存 HTML、CSS 和 JavaScript，并为每次桌面启动及静态资源添加版本参数，修复程序已更新但 WebView2 仍加载旧界面、导致“下一步”继续无响应的问题。
0.16.3 修复步骤或页面切换时音乐播放器清空了音频地址、却保留旧曲目标识，导致回到第三步后波形仍显示但独立预览变为 0:00/0:00 的问题。
0.16.4 素材弹窗中被其他成片占用的灰色视频支持双击重新激活并自动选中，复用许可随当前方案自动保存；单击灰色片段会提示占用原因。修复音乐波形的指针事件阻断双击重新激活的问题。
0.16.7 整体导出增加真实批次进度条，显示已完成/总数、当前成片、成功数和失败数；单条失败仍继续后续任务，并阻止重复点击启动同一批导出。
0.16.8 步骤三的灰色视频片段和灰色音乐区间支持可靠双击重新启用；单击继续显示占用提示，复用许可会自动保存。当前成片已经存在的视频片段仍禁止重复添加。
0.16.9 步骤三的可复用灰色视频增加居中的“已被使用 · 双击启用”醒目标识，提示区域不会阻断卡片双击操作。
0.14.2 第二步审核队列增加钩子删除。删除后该钩子不会进入组合和整体导出，仅清理项目派生音频与预览，原始视频始终保留。
0.14.1 修复自动保存已经成功、但右侧审核队列仍读取旧状态并显示 0/N，导致步骤三按钮被错误禁用的问题。已保存的审核结果会立即同步到队列与进度。
0.14.0 将第二步改为视频与结果在左、可滚动审核队列在右，候选点、滑杆和换条均自动保存；全部审核后才统一进入第三步。第三步打开当前钩子即自动生成独立预览，最终只保留整体导出；第一步增加真实任务进度，并修复旧预览文件导致的 FFmpeg 空流错误。

桌面版项目、AI 设置和星标素材保存在 %LOCALAPPDATA%\HoMix\Data，升级或替换程序文件夹不会覆盖这些数据。首次运行会自动迁移旧版 SceneSift 数据和便携包 data 内容。

HoMix 的运行不需要 Codex。Codex 只用于开发阶段，不属于软件依赖。
