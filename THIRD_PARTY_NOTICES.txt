HoMix includes the Gyan FFmpeg 8.1.2 Essentials Windows build in the tools
directory. This build is licensed under GPLv3. Its LICENSE and README.txt are
included next to ffmpeg.exe and ffprobe.exe. Build and corresponding source
information: https://www.gyan.dev/ffmpeg/builds/

The macOS distributions include architecture-specific FFmpeg and FFprobe
binaries from the @ffmpeg-installer and @ffprobe-installer npm packages.
FFmpeg build 92718-g092cb17983 is distributed under the package's stated
FFmpeg open-source license terms; the GPLv3 text is included next to the
binaries. Corresponding FFmpeg source information:
https://github.com/FFmpeg/FFmpeg/commit/092cb17983
https://www.osxexperts.net/
https://evermeet.cx/ffmpeg/

The Apple Silicon FFprobe binary is based on FFmpeg 4.4.1 and the Intel
FFprobe binary is build 20230213-f8d6d0f. Package and source information:
https://formulae.brew.sh/formula/ffmpeg
https://github.com/FFmpeg/FFmpeg

The macOS desktop shell uses Electron. Electron's license and Chromium third
party notices are included inside each application bundle. Project and source
information: https://github.com/electron/electron
