# HoMix

一个无需账号、只在本机运行的素材拆分、批量钩子识别、人工/自动成片编排工作台。

主流程分为三步：素材准备与项目设置 → 钩子识别与切点确认 → 成片编排与导出。混剪素材、钩子和音乐分别可选；纯混剪会跳过第二步，仅钩子项目可在第三步直接导出。

## 启动

### Windows 便携版

运行 `build-portable.ps1` 后，双击 `dist\HoMix\HoMix.exe`。便携包包含
Node.js 运行时，不要求目标电脑另行安装 Node。EXE 使用 WebView2 打开本地桌面窗口，
文件与文件夹由窗口直接选择。启动器采用单实例；重复双击会唤醒现有窗口，关闭主窗口
会同步结束 Node、FFmpeg 等后台进程，端口被占用时自动选择可用端口。

独立发行包同时包含 FFmpeg 8.1.2 Essentials，不依赖 Codex、ECutPro 或系统
Node.js/FFmpeg。Codex 只参与开发过程，不属于 HoMix 的运行链路。

### 源码模式

双击 `start.cmd`。程序会自动打开浏览器并访问：

`http://127.0.0.1:47821`

关闭黑色命令窗口即可停止程序。

## 当前功能

- 批量选择 MP4、MOV、MKV、AVI、WebM 等视频。
- 原生文件/文件夹选择器与 Windows 视频拖放，不再冷启动 PowerShell 对话框。
- 使用 FFmpeg 场景变化检测生成连贯内容段；默认不把黑场、闪切和相似设计转场拆成独立碎片。
- 可调镜头连贯度和最短连续段时长。
- 直接保存转场帧的原始 PTS；相邻片段使用 `[本段首帧, 下段首帧)` 半开区间，不提前、不重叠、不丢帧。
- 每个镜头可按源视频帧率逐帧修正入点和出点，适合清理边缘残留的下一镜头画面。
- 缩略图网格、视频预览、片段跳转。
- 自动编号标签、单个改名、批量选择。
- HoMix 可自动启动本机 Ollama，也可使用 GLM 云端视觉模型生成结构化中文语义标签。
- 视觉模型综合镜头开头、中间、结尾三张定格帧，生成主体、场景、动作、景别、镜头运动、叙事角色、连续性和脚本匹配关键词。
- 空镜和钩子可在第一步一次导入；后端同时执行空镜拆分与钩子识别，不再先等拆分、再等模型。
- 混剪素材、钩子和音乐均可独立启用；支持纯混剪、仅钩子、钩子加混剪三种项目结构。
- 钩子视频支持限流并发批量识别；视觉模型结合叙事逻辑判断钩子/产品分界，高置信度结果自动确认，人工只复核低置信度项目。模型超时也直接降级为待确认，不阻塞整批任务。
- 确认钩子只记录精确切点，导出时才裁切钩子原画面，取消第二步不必要的画面预编码。
- 组合阶段默认自动铺满，也可人工添加、替换、删除、调序并调整每段实际使用时长。
- 钩子原声只跟随钩子画面；后段混剪默认 15 秒并可调整，上传音乐可独立选择和拖动入点。
- 自动计划默认硬切；只有明确需要的单个衔接才手动改为黑场或交叉溶解。
- 组合时间线显示每个片段的缩略图、源文件、入点和实际使用时长；可点击逐段播放，也可在最终导出前生成整条低清预览。
- 多条钩子分别保存独立的组合顺序、转场和预览状态；组合页可使用上一条/下一条逐条监看，最后一次批量导出。
- 每次“重新自动铺满”都会生成新的随机种子；其他钩子已使用的空镜会被严格排除，素材不足时明确停止该条而不会重复使用。
- 成片确认后才锁定所用片段；后续成片选择器会把已用片段沉底、置灰并禁止再次选择，但仍允许标星。
- 钩子审核媒体使用独立 hookId、短时本地缓存和相邻条目预读，切换不再等待项目保存，也不会残留上一条画面。
- 导出完成后常驻显示每条钩子的成功/失败状态、成片路径和导出文件夹入口。
- 粘贴文案后按语义与叙事位置规划镜头，仍支持约 15 秒 / 10 镜头的单文件画面粗剪。
- 支持“逐行批量匹配”：每个非空文案行匹配一个不同镜头，并对同源近邻和视觉语义相似镜头强制降权。
- 镜头卡片可一键星标；星标时自动精确导出并加入可播放、可改名的本地优选素材库。
- 确认切点后的钩子也可加入星标库；星标内容只允许手动加入项目，不再自动参与混剪。
- FFmpeg 使用低进程优先级，并以小批次生成缩略图，降低分析时对系统交互的影响。
- 全部使用精确重编码切分，避免从非关键帧直接复制码流造成花屏或马赛克。
- 导出兼容 LosslessCut 的三列 CSV。
- 源码模式项目保存在本程序的 `data` 文件夹；桌面发行版保存在 `%LOCALAPPDATA%\HoMix\Data`，更新软件不会覆盖项目和星标素材库。首次启动新版会自动迁移旧的 SceneSift 数据。

## FFmpeg

程序按以下顺序查找 FFmpeg：

1. 环境变量 `HOMIX_FFMPEG` / `HOMIX_FFPROBE`（仍兼容旧的 `SCENESIFT_*` 名称）
2. 本程序 `tools` 文件夹
3. 本机现有 ECutPro 的 FFmpeg 文件夹（只调用，不复制或修改）
4. 系统 PATH、Scoop 或 Chocolatey

如需完全脱离其他软件，可从 FFmpeg 官方发行渠道取得 `ffmpeg.exe` 和
`ffprobe.exe`，放入 `HoMix\tools`。

## 视觉 AI 标签（可选）

安装 Ollama 后，HoMix 会在进入“AI 设置”或实际使用视觉分析时按需检测，
需要本地识图时才自动启动 `http://127.0.0.1:11434`，普通启动不会唤起 Ollama。
可在“AI 设置”中一键安装 `qwen3-vl:4b`；只有 Ollama 明确认定支持 vision
的模型才会出现在下拉框中。本地识图不会把图片发送到互联网。

也可以在界面右上角“AI 设置”中选择 GLM，填写支持图片输入的模型名称与
API Key。默认模型为 `glm-4.6v-flash`。密钥通过 Windows 当前账户的 DPAPI
加密保存在本机，不会明文写入项目 JSON，也不会通过状态接口返回。

## 数据与隐私

- 服务只监听 `127.0.0.1`，局域网和互联网无法访问。
- 视频路径、缩略图和项目 JSON 都留在本机。
- 只有启用 GLM 标签时，镜头缩略图会按需发送到所配置的 GLM API。
- HoMix 不包含账号、邀请码、遥测或云端上传功能。
